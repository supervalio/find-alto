## Прямые конкуренты

### 1. FDC.am — Fashion & Design Chamber Armenia 🔴

| Параметр | Значение |
|----------|----------|
| **Тип** | Официальный каталог армянских дизайнеров |
| **Охват** | Только Армения |
| **Финансирование** | Евросоюз (грант) |
| **Контент** | Профили дизайнеров, новости, Yerevan Fashion Week |
| **Монетизация** | Гранты + членские взносы |
| **Минусы** | Нет страниц вещей, нет цен, нет культурного контекста, нет структуры «страна→город→категория→вещь» |

> **Вывод:** FDC — B2B-инструмент для индустрии. Find Alto — B2C-гид для конечного пользователя. **Не прямой конкурент, а источник данных.**

### 2. Georgia.to / Made in Georgia 🟡

| Параметр | Значение |
|----------|----------|
| **Тип** | Travel-гид с разделом о дизайнерах |
| **Охват** | Только Грузия |
| **Формат** | Статья-лонгрид (не база данных) |
| **Контент** | 8-10 дизайнеров, пара абзацев на каждого, список бутиков |
| **Монетизация** | Продажа туров (основной бизнес) |
| **Минусы** | Нет страниц вещей, нет цен, нет поиска по категориям, нет админки |

> **Вывод:** Статья в блоге туристического агентства. **Не конкурент.** У Find Alto — структурированный каталог с ценами и историями.

### 3. Not Just a Label (NJAL) 🟡

| Параметр | Значение |
|----------|----------|
| **Тип** | Глобальная платформа emerging-дизайнеров |
| **Охват** | 150+ стран, 35,000+ дизайнеров |
| **Формат** | Профили дизайнеров + e-commerce |
| **Монетизация** | Подписка дизайнеров + комиссия с продаж |
| **Минусы** | Нет географической навигации, нет культурного контекста, нет фокуса на СНГ |

> **Вывод:** Крупнейший глобальный игрок, но **не фокусируется на локальном контексте**. Для Армении — всего 5-10 дизайнеров (из 35K). Find Alto выигрывает глубиной: истории, why locals wear, цены.

## Косвенные конкуренты

### Instagram (Meta) 🔴

Самый сильный непрямой конкурент. Дизайнеры ведут Instagram, продают напрямую через Direct. Покупатели ищут по хештегам и геотегам.

**Почему Find Alto лучше:**
- Структурированный каталог вместо хаоса хештегов
- Сравнение цен и дизайнеров в одном месте
- SEO-трафик из Google (Instagram не индексируется)
- Истории и культурный контекст, которых нет в Instagram

### Концепт-сторы (cone.yerevan, 5Concept, Chai Khana, Chaos) 🟡

Это партнёры, а не конкуренты. Find Alto приводит к ним трафик → они заинтересованы в коллаборации.

### Глобальные маркетплейсы (Etsy, Farfetch)

Для локальных СНГ-дизайнеров почти нерелевантны. Армянские дизайнеры не сидят на Etsy.

## Оценка ниши: насколько это выгодно?

### Размер рынка

| Страна | Дизайнеров (оценка) | Объём fashion-рынка |
|--------|:---:|:---:|
| Армения | ~25-30 активных брендов | ~$150M |
| Грузия | ~40-50 активных брендов | ~$250M |
| Казахстан | ~60-80 активных брендов | ~$500M |
| Узбекистан | ~30-40 активных брендов | ~$200M |
| Украина | ~200+ активных брендов | ~$1B |
| **Итого СНГ** | **~400 доступных дизайнеров** | **~$2.5B** |

### Тренды в пользу проекта

1. **Рост интереса к локальному.** Slow fashion, sustainability, поддержка местного производителя — глобальный тренд
2. **СНГ-дизайнеры не имеют digital-витрины.** 80% армянских дизайнеров — только Instagram. Ни сайта, ни каталога
3. **Туризм в СНГ растёт.** Армения: +20% турпотока в 2023-24. Туристы ищут unique local experiences
4. **Fashion Week в регионе.** Yerevan FW, Tbilisi FW, Kazakhstan FW — растёт международное внимание
5. **Нет единой платформы.** Нет ни одного сайта, который бы агрегировал локальных дизайнеров СНГ с ценами и историями

### Риски

| Риск | Вероятность | Смягчение |
|------|:---:|-----------|
| Низкий трафик → нет рекламодателей | Средняя | Instagram-коллаборации, SEO |
| Дизайнеры не заинтересованы в featured | Низкая | Бесплатный профиль уже даёт им ценность |
| Конкуренция со стороны FDC/госструктур | Низкая | У них другой формат и B2B-фокус |
| Санкции/платежи в СНГ | Средняя | ЮMoney + крипта + наличные для рекламодателей |

## Вердикт: перспективность

### Три цифры

| Метрика | Значение | Что это значит |
|---------|:---:|---|
| **0** | Конкурентов | Ни одного структурированного B2C-гида по локальным дизайнерам СНГ |
| **400** | Дизайнеров | Доступно для добавления в каталог (Армения → Украина). Каждый — страница в Google |
| **$2.5B** | Объём рынка | Совокупный fashion-рынок СНГ. Даже 0.01% в виде рекламы/комиссий = $250K |

### Три тренда

1. **Slow fashion** — глобальный сдвиг от Zara к вещам с историей. Люди хотят знать, кто сшил и почему
2. **Туризм в СНГ растёт** — туристы ищут «что привезти кроме магнита». Армения +20% турпотока
3. **SEO-вакуум** — по запросам «армянские дизайнеры», «локальная мода Ереван» нет ни одного приличного сайта. Каждая страница Find Alto займёт топ выдачи

### Главный риск

**Контент.** Не конкуренты, не технология. Нужно вручную собирать, проверять и писать. Но именно этот барьер защищает проект от копирования — никто не захочет повторить эту работу.

### Ставка

Стать тем, чем стал «Афиша» для ресторанов, но для локальной моды в СНГ.
